# Components Map

- v1, the plan, drawn before any application code (commit a3474cb): [SVG](components-map-v1.svg), [PNG](components-map-v1.png)
- v2, what was actually built: [SVG](components-map-v2.svg), [PNG](components-map-v2.png)

Both are generated by `scripts/render-map.mjs` from `scripts/map-data-v1.mjs` and `scripts/map-data-v2.mjs` (`npm run map -- v2`).

Swimlane rows: Cron / Vercel, News and web sources, Gemini Flash, Code (validators and scorer), Supabase, HubSpot, Resend, Arjun.
Columns: Trigger, Input, Context, Processing, AI, Output.
The orange dashed line separates Arjun-owned data from system-written data (D02: the system never writes Arjun-owned columns).

Changes from v1 to v2:
- HubSpot now has a deal pipeline, "Enterprise Leads", and the sync reads deal stages into accounts.stage.
- The churn-risk workflow runs in code, because the workflows API was refused.
- The database layer has a PGlite fallback with seed data when DATABASE_URL is missing.
- Auth is a Next.js 16 proxy that only allows ARJUN_EMAIL.
